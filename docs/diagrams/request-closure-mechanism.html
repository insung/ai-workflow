자유롭게 묻되, 결정론적으로 닫는다

스킬은 사용자의 암묵지를 질문과 읽어주기로 드러내고, 스크립트는 답의 의미를 대신 판단하지 않은 채 필수 구조·충돌·열린 중요 항목·승인 정합성만 검사합니다.

스크립트가 검증할 것과 검증하지 않을 것

스크립트는 필수 필드 존재, 서로 모순되는 값, materialOpenItems, 승인 대상의 digest처럼 같은 입력에서 같은 결과가 나오는 항목만 검사합니다. “사용자가 정말 원하는 뜻인가”는 기계적으로 판정하지 않고, 스킬의 읽어주기와 사용자의 수정·승인으로 확인합니다.

자유도를 유지하는 곳 질문의 표현, 순서, 예시, 시각화는 요청의 맥락과 중요도에 맞춰 바뀝니다.
강제성을 두는 곳 중요한 미결정이 남았으면 닫지 않고, 승인된 Frame이 바뀌면 재승인을 요구합니다.

닫기의 깊이

  • 모든 요청을 같은 질문 수로 제한하지 않습니다.
  • 영향과 비가역성이 클수록 확인 범위를 넓힙니다.
  • 사소한 선택은 provisional로 두고 나중에 바꿀 수 있습니다.
  • 최종 승인 권한은 언제나 사용자에게 있습니다.

v1은 질문 횟수를 제한하지 않습니다. 같은 중요 미결정에서 두 차례 진전이 없으면 needs-user-direction으로 멈추며, 사용자가 답하거나 재분류하면 다시 시작합니다.
